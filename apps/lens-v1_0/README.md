# Lens v1.0 Snapshot

This directory preserves the pre-redesign Lens runtime as a legacy source snapshot.

It reflects the older shared-device, round-robin, discussion-oriented flow and should be treated as reference material, not the forward product direction.

The current redesign work is defined in:

- `apps/lens/docs/v1-redesign-spec.md`

## Commands

After dependencies are installed:

- `npm run dev`
- `npm run build`
- `npm run lint`
