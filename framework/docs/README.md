# Framework Docs

This directory is organized around the current, stable workflow rather than the pipeline's migration history.

## Start Here

- `story-authoring.md` explains how to write a story design doc, author episode drafts, and iterate with `/validate_story`.
- `artifacts-generation.md` explains how the story-level gate feeds the episode pipeline: `/create_episode`, `/create_transcript`, and `/build_assistive_package`.
- `operator-guide.md` is the short runbook for day-to-day operation.

## Supporting Docs

- `conceptual-framework.md` explains the pedagogical model: lenses, facets, and explanatory variables.
- `architecture.md` explains repository structure, system boundaries, and where artifacts live.

## Archive

`archive/` contains migration-era specs, implementation notes, and retired supporting docs. Treat those files as historical reference, not the current workflow.
