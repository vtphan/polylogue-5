# Lens v1.1

This directory is the clean-slate app for the redesigned Lens student runtime.

The canonical product and implementation docs live in:

- `apps/lens/docs/v1-redesign-spec.md`
- `apps/lens/docs/technical-specs-v1.md`
- `apps/lens/docs/wireframes-v1.md`
- `apps/lens/docs/implementation-readiness-v1.md`

This app should implement the current v1 direction:

- single student
- no writing
- no discussion
- read full episode first
- one or two warm-ups
- level-based challenge flow
- scaffold ladder
- badge/progress feedback

## Commands

After dependencies are installed:

- `npm run dev`
- `npm run build`
- `npm run lint`
