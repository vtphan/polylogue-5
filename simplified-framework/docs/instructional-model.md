# Simplified Instructional Model

This document defines the instructional model for the simplified Lens framework.

It is intentionally narrower than the current Lens conceptual framework.

## 1. Primary Goal

The primary goal is:

Help students practice a small set of critical-thinking habits while reading short discussion episodes.

The app should help students do three things well:

1. notice weak or incomplete reasoning
2. understand why it is weak or incomplete
3. recognize the same pattern again in a new turn

That is the instructional core.

## 2. What Students Should Learn

For the simplified model, students should not be asked to learn the full hidden taxonomy.

They should learn a small set of plain-language critical-thinking moves:

- jumping to a conclusion
- not enough evidence
- ignoring another perspective
- trusting a source too quickly
- missing important conditions or consequences

These are the main student-facing categories.

## 3. One Episode, One Main Lesson

Each episode should primarily teach one main flaw.

It may include additional supporting flaws, but it should not try to teach many concepts at once.

A good episode structure is:

- one main flaw
- optionally one additional supporting flaw
- several clear examples of the main flaw across the episode

This makes transfer and repetition more likely.

## 4. Teaching Loop

The core teaching loop should be:

1. read a short discussion episode
2. learn one example directly
3. practice recognizing the same move in 3 to 5 turns
4. receive immediate feedback
5. leave with one transfer takeaway

This should feel simple and finishable.

## 5. Interaction Model

The simplified instructional model assumes:

- no student writing
- no peer discussion requirement
- no lens selection by the student
- no consensus task

The default interaction should be:

- show one turn
- ask one multiple-choice question
- let the student answer
- show immediate feedback
- continue

Support should stay lightweight.

## 6. Feedback Model

Feedback is instructional, not merely evaluative.

A useful feedback pattern is:

- if correct:
  affirm briefly and explain why the answer fits
- if partially correct:
  explain what the student noticed and what is still missing
- if incorrect:
  redirect attention to the reasoning gap
- if unsure:
  provide one hint, then allow retry

Feedback should be short, specific, and tied to the turn.

## 7. Warm-Ups

Each episode should begin with:

- one modeled warm-up
- optionally one guided warm-up

Warm-ups should explicitly teach:

- what the speaker is claiming
- what reason is being offered
- what is missing or weak
- what critical-thinking lesson to carry forward

Warm-ups should show the answer, not merely imply it.

## 8. Transfer Goal

The end of an episode should reinforce one plain-language takeaway, such as:

- a strong thinker checks whether the reason really supports the conclusion
- a strong thinker asks whether there is enough evidence
- a strong thinker checks whose perspective is missing

The student should leave with one memorable habit, not a long taxonomy.

## 9. Hidden Conceptual Structure

The simplified model can still use the richer Lens concepts underneath.

Internally:

- lens can remain a broad family
- facet can remain the hidden target
- cognitive bias or social dynamic can remain the explanation layer

But students should mostly see:

- plain-language move labels
- plain-language questions
- plain-language explanations

## 10. Success Criteria

The simplified model is successful if a student can:

- finish an episode without confusion
- explain in plain language what was wrong or incomplete in a turn
- recognize the same kind of issue in later turns
- describe one useful critical-thinking habit they practiced

If the product teaches those things clearly, it is doing its job.
