# Simplified Conceptual Model

The simplified framework teaches one student-facing layer: reasoning flaws.

## Core Rule

Each teachable turn should be organized around one primary flaw from `reference/flaw-taxonomy.yaml`.

The runtime and lesson package should stay in plain language. Hidden analytic detail is optional and must not be required for the student experience.

## Current Student-Facing Flaw Set

- jumping to a conclusion
- not enough evidence
- ignoring another perspective
- trusting a source too quickly
- missing important conditions or consequences

## Design Implication

Episodes should usually center on one main flaw, with an optional secondary flaw used only when it strengthens the lesson without muddying it.
