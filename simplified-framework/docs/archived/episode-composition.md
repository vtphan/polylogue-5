# Episode Composition

This document defines current transcript-writing guidance for the simplified framework.

## Composition Rules

- Write a plausible scene first, not a disguised worksheet.
- Not every turn needs a flaw.
- Most teachable turns in an episode should express the primary flaw.
- Secondary flaws should be used sparingly.

## Teachable-Moment Target

Plan for roughly 5 to 7 candidate teachable moments per episode:

- about 2 warm-up candidates
- about 3 to 5 level candidates

This is guidance, not a hard validator rule.

## Turn Count Guidance

- preferred range: 10 to 16 turns
- hard cap: 20 turns unless there is a strong reason

## Quality Standard

A good episode gives the package builder enough clear teachable turns while still reading like a real conversation.
