# Simplified Lens App

This directory is the student-facing app for the simplified Lens framework.

The canonical simplified-framework docs live in:

- `../docs/conceptual-model.md`
- `../docs/instructional-model.md`
- `../docs/package-schema.md`
- `../docs/pipeline-overview.md`

This app should implement the simplified direction:

- single student
- no writing
- no discussion
- read first
- explicit warm-ups that show the answer
- short, low-friction turn challenges
- immediate feedback on reasoning flaws
- simplified artifact consumption from `../artifacts/` and `../configs/`

## Commands

After dependencies are installed:

- `npm run dev`
- `npm run build`
- `npm run lint`
